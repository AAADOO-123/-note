1. **第一次学**：通读《复习笔记》，先看「30 秒地图」，再按章节读。
2. **动手时**：打开《实验清单》，照「通用操作流程」做，重点做实验 1-1。
3. **忘得快时**：只看每篇顶部的「⚡ 考前回忆卡」。
4. **查漏**：做《复习笔记》里的「复习自测题」，对不上再回正文。
5. **临考前**：过一遍《Harness 速览》+ 三篇的「🧠 易混点」。
